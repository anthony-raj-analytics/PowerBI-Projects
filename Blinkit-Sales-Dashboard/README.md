## 📌 Project Overview

An interactive **Power BI Sales Analysis Dashboard** developed to analyze Blinkit's grocery sales performance, product categories, customer ratings, and outlet operations.

This project focuses on transforming raw sales data into actionable business insights through data modeling, DAX calculations, and interactive visualizations.
